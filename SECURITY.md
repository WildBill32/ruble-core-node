# Security policy

## Supported versions

`Ruble Core 1.0.1` is the current supported mainnet release. Older Ruble
builds and rehearsal networks are not supported. Verify published checksums
and, where supplied, platform signatures before installation. The project does
not claim that this release has received an independent security audit.

## Reporting a vulnerability

Do not disclose suspected wallet, consensus, network or release-security
vulnerabilities in a public issue. Use GitHub private vulnerability reporting
for this repository (Security -> Report a vulnerability). If that control is
not available, contact the project operator through <https://rublecore.org/>
and request a private channel without including exploit details in the first
message.

Ordinary, non-sensitive bugs may be reported through this repository's issue
tracker. Never attach wallet databases, seed phrases, private keys, RPC
cookies, credentials or personal data.

Bitcoin Core and Fractal Bitcoin security contacts are not Ruble Core support
contacts and must not receive Ruble-specific reports unless an issue is first
confirmed to affect their upstream software.
